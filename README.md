# Business-Card-Template
Template of Business Card I can use to network with possible recruiters
Making my Profile Business Card

General Summary of Project:

When it came to the making of this “business card” I wanted to try a few different elements from various topics I had been learning concerning HTML and CSS (I would later on add Javascript since it was needed to meet my creative choices.) For sake of having a template moving forward I went with the whole Neo gimmick so I am not openly sharing my data but when needed I can very easily replace that with my actual name, phone and email when needed.With that being said, I do not mind sharing my GitHub and Linkedin so I included those as a form of digital signature that this is mine!

At first this was a very basic business card, had the format that you see from the start, image pfp on the left hand side, with Name followed by Role, and then a divider putting the links and contact information. Getting to this step was not a challenging task. However as many would know, at this point it is a very bland looking business card and so I decided to beef it up by going full matrix theme on it and get to the results you see it as.

This for sure was the challenging part for finding out how to make matrix rain effect as a background and then following that structure to be sound throughout the whole project proved to be a bit more janky then I would of expected, however luckily for me there was plenty of youtube tutorials and general guides for me to watch, learn, and experiment with while trying to get it to work on my project.

The bottom line is, I learned a great deal at what roles HTML, CSS, and Javascript play when it comes to their perspective roles. HTML is used in order to structure and establish what exists, CSS is used for appearance formatting the overall project and how it appears/interacts, Javascript to establish behavior of the site (In this case creating the Matrix Rain effect).

I am overall satisfied with the results of the project and I definitely had fun figuring things out, a not so fun part was troubleshooting but I suppose that is the case with any coding adventure.
